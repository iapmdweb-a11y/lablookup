Handbook manager

Add a new edition, choose which one is current, and remove old ones. Then download handbooks.json and upload it to your website. The LabLookup app reads that file every time it opens.

Already have a handbooks.json?

After you download

  1. Upload the new PDF to the handbooks folder on your website, using exactly the file name shown above (spaces become hyphens).
  2. Upload the new handbooks.json next to the LabLookup page, replacing the old one.
  3. Delete the removed editions’ PDFs from the handbooks folder. Removing an edition here only takes it off the list; the PDF stays on the website until you delete it.
  4. Staff see the new edition the next time they open the app.
